# Personal Portfolio Website

## Project Overview

This project is a responsive personal portfolio website created using HTML5 and CSS3.

The portfolio is designed to showcase personal information, technical skills, projects, and contact details in a clean and professional layout.

## Features

- Responsive profile/hero section
- Name and professional role
- Profile photo/avatar section
- About Me section
- Technical Skills section
- Projects section with project cards
- GitHub project links
- Contact section
- LinkedIn and GitHub links
- Smooth scrolling navigation
- Responsive design for desktop, tablet, and mobile screens
- Consistent colour scheme and typography

## Technologies Used

- HTML5
- CSS3
- Google Fonts

## Website Sections

### 1. Hero Section
Introduces the portfolio owner with their name, professional role, and profile/avatar.

### 2. About Me
Provides a short introduction about the portfolio owner, their background, interests, and goals.

### 3. Skills
Displays the technical skills in a clean and organized layout.

### 4. Projects
Contains project cards with project titles, descriptions, and GitHub links.

### 5. Contact
Provides contact information along with placeholder social links such as LinkedIn and GitHub.

## Responsive Design

The website is designed to work properly on:

- Desktop
- Tablet
- Mobile devices

CSS media queries and responsive layouts are used to ensure that the content remains readable and usable on smaller screens.
